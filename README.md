# Microdosing Journal

A cross-platform microdosing journal and wellness protocol tracker built with **React Native (Expo)**.

## Tech Stack

- **Framework:** React Native with Expo SDK
- **Language:** TypeScript
- **State Management:** useReducer (TEA pattern — Model-View-Update)
- **Local Database:** SQLite (encrypted, offline-first)
- **Sync:** PowerSync + Supabase (E2E encrypted)
- **BLE Sensors:** react-native-ble-plx
- **Health Data:** react-native-health (iOS) + react-native-health-connect (Android)
- **Navigation:** Expo Router (file-based)
- **Platforms:** iOS, Android, Web

## Overview

A privacy-first wellness companion for tracking supplement protocols, mood, energy, biometrics, and daily journaling. Features a unique Chakra-based wellness framework, BLE heart rate/EEG integration, and offline-first multi-device sync.
